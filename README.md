## 📖 系统定位

**智汇中枢**是一套面向企业内部的 AI 知识管理平台，解决三大核心问题：

1. **资料碎片化** — 各部门资料散落各处、格式不一、难以检索
2. **信息孤岛** — 部门之间不了解彼此的业务、文档与日程
3. **知识沉淀难** — 经验与知识只存在员工脑中，无法沉淀为组织资产

**核心流程**：上传资料 → AI 自动加工（分类 / 提关键词 / 摘要 / 部门推荐 / 重要性评分 / 建立关联）→ 全员可检索、可问答、可看全局图谱。

## 🏗️ 技术架构（云端版）

**零后端、零框架、零构建**：浏览器端单页应用，所有 AI 处理与数据存储均在本机浏览器内完成。

```
enterprise-knowledge-hub/
├── index.html           # 单页应用入口（7 大模块 + 上传/AI处理/详情/日程弹窗）
├── css/
│   └── style.css        # 设计系统：CSS 变量主题、响应式卡片布局
└── js/
    ├── ai-engine.js     # 本地 AI 引擎（浏览器端）：分类/关键词/摘要/关联/问答
    ├── local-server.js  # LocalAPI：在浏览器内复刻后端 REST 接口（localStorage 存储）
    └── app.js           # 前端视图渲染与交互逻辑
```

- **数据存储**：浏览器 `localStorage`（键前缀 `ekh_`），文档原文与 AI 加工结果均落本地
- **备份机制**：侧边栏「导出数据 / 导入数据」一键 JSON 备份与恢复，支持换设备迁移

## 🧠 AI 引擎说明

内置**本地 AI 引擎**——不依赖任何外部大模型 API，**所有文档数据不出浏览器**：

| 能力 | 实现方式 |
|------|---------|
| 文档分类 | 8 类业务文档规则匹配（方案/PRD/白皮书/报告/手册/规范/纪要…） |
| 中文关键词提取 | 中文 n-gram（2~4 字）+ 停用词/粘着词过滤 + 领域词表加权 + 子串去重 |
| 摘要生成 | 抽取式：关键词密度 × 位置权重 × 长度加权，取 Top-3 句 |
| 部门推荐 | 六大部门领域词表打分（研发/市场/财务/人力/运营/法务） |
| 文档关联 | 同部门 + 共享关键词（≥2 个）自动建边，驱动知识图谱 |
| 智能问答 | 意图识别（日程/部门/文档/总览）+ 相关度排序检索，回答带来源 |
| 重要性评分 | 文档类型、信息密度、关键标志词、数据含量加权 |

> **架构可演进**：如需接入企业私有 LLM，只需将 `ai-engine.js` 中的规则算法替换为 API 调用，其余模块接口契约保持不变。

## 📁 支持的文件格式

文本抽取覆盖 `txt / md / pdf / doc / docx / xlsx / pptx` 等常见办公格式（docx/xlsx 通过解压 XML 提取正文，pdf 走流式文本解码），单文件最大 50MB；也支持直接粘贴文本录入。

## 🚀 快速开始

**方式 A：直接使用线上版**

打开 https://jayceyilmali568-rgb.github.io/enterprise-knowledge-hub/ 即可体验，无需安装任何东西。

**方式 B：本地运行**

将本仓库克隆/下载到本地，任选一种静态服务器指向仓库根目录：

```bash
# 方式 1：Node
npx serve .

# 方式 2：Python
python -m http.server 8080

# 方式 3：VS Code 安装 Live Server 插件，右键 index.html → Open with Live Server
```

然后浏览器访问 `http://localhost:8080`。

无需 `npm install`、无需构建——仓库本身就是可直接托管的静态站点。

## 💾 数据与备份

- 数据保存在**当前浏览器的 localStorage** 中，换浏览器/设备不会自动同步
- 重要数据请用侧边栏「**导出数据**」生成 JSON 备份文件；换设备后「**导入数据**」即可恢复
- 清浏览器缓存/站点数据会清空上传内容，重置按钮可恢复内置示例数据

## 🔐 数据安全与隐私

- ✅ 无后端服务器、无外部 API 调用、无第三方统计脚本
- ✅ 文档解析、AI 分类/摘要/问答全部在浏览器本地完成，上传内容**不会离开你的设备**
- ✅ 适合对数据外发敏感的企业内部演示与试用场景
- ⚙️ 生产化升级路径：可平滑接入企业私有 LLM 或后端服务（接口契约已预留）
